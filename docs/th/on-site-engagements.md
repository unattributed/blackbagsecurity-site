      <h1>การดำเนินงานนอกสถานที่</h1>
      <p>การส่งมอบแบบลงพื้นที่ สำหรับการประเมิน การยืนยัน การสนับสนุนเหตุการณ์ และการให้คำปรึกษาทางเทคนิค เมื่อสถานที่และบริบทการปฏิบัติงานมีความสำคัญ</p>
    </div>

    <div class="split">
      <div class="stack stack--signal stack--scope reveal delay-1" data-reveal>
        <h3>วัตถุประสงค์และความเหมาะสม</h3>
        <ul class="outcomes">
          <li><span class="mono">การประเมิน:</span> การทดสอบสถานที่ เครือข่าย แอปพลิเคชัน และเวิร์กโฟลว์ของผู้ปฏิบัติงาน ภายใต้ขอบเขตที่กำหนด</li>
          <li><span class="mono">การยืนยัน:</span> การยืนยันเส้นทางโจมตีและมาตรการควบคุม ภายใต้ช่วงเวลาที่ตกลงไว้ในระบบจริงหรือระบบใกล้เคียงระบบจริง</li>
          <li><span class="mono">การสนับสนุนเหตุการณ์:</span> การจำลองฝ่ายตรงข้ามแบบเจาะจง เพื่อยืนยันสมมติฐานการตอบสนอง</li>
          <li><span class="mono">การให้คำปรึกษา:</span> เวิร์กช็อปทางเทคนิคสำหรับการจัดลำดับความสำคัญการเสริมความมั่นคงและการวางแผนแก้ไข</li>
        </ul>
      </div>
      <div class="stack stack--signal stack--safety reveal delay-2" data-reveal>
        <h3>การควบคุมการเข้าถึงและความปลอดภัย</h3>
        <ul class="outcomes">
          <li>งานลงพื้นที่ดำเนินภายใต้การดูแลของเจ้าหน้าที่ลูกค้าที่ได้รับมอบหมาย หรือรูปแบบการกำกับดูแลที่ได้รับอนุมัติ</li>
          <li>กติกาการปฏิบัติงานกำหนดเงื่อนไขการหยุด ระบบที่ห้ามแตะต้อง และเส้นทางการยกระดับ</li>
          <li>ช่วงเวลาทดสอบและมาตรการปกป้องระบบจริงถูกตกลงกันก่อนเริ่มงาน</li>
          <li>กิจกรรมจะหยุดทันทีเมื่อความเสี่ยงเกินกว่าระดับที่ตกลงไว้</li>
        </ul>
      </div>
    </div>

          <li>การถ่ายภาพ วิดีโอ และภาพหน้าจอ จะทำเมื่อได้รับอนุญาตอย่างชัดแจ้งเท่านั้น</li>
          <li>การจัดเก็บและการโอนย้ายใช้ช่องทางที่ปลอดภัยและได้รับอนุมัติจากลูกค้า</li>
          <li>สำหรับข้อกำหนดด้านที่ตั้งประเทศหรือที่อยู่ข้อมูล การจัดการสามารถปรับให้สอดคล้องกับข้อจำกัดที่ตกลงกันได้ หากทำได้ในทางปฏิบัติ</li>
        </ul>

          <li>มีการยกระดับทันทีเมื่อพบประเด็นวิกฤตหรือเกิดผลกระทบที่ไม่คาดคิดต่อการปฏิบัติงาน</li>
          <li>มีการทบทวนข้อค้นพบฉบับร่างเพื่อยืนยันบริบทก่อนสรุปผล</li>
          <li>สามารถเลือกเพิ่มการยืนยันการแก้ไขหรือการทดสอบซ้ำหลังการแก้ไขได้</li>
        </ul>
